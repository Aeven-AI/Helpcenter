# Where your work lands

Aeven puts results where you can use them next: in the conversation, in the folder it is working in, or in a preview you can open on the side.

## In the conversation

Answers arrive as text: a summary, a table, a plan, an explanation. Copy them from the reply when you want them elsewhere.

## In your folder

When a task produces a file — a document, a spreadsheet, a script, a renamed set of images — Aeven writes it into the folder you chose and names it in the conversation. The files sidebar shows the folder as it changes.

## On the side

Files, pages, and the terminal open in the right sidebar while Aeven works, so you can look at what it is doing without leaving the conversation. Long outputs stay available there after the task finishes.

## Attachments you sent

What you attach is read as part of the request. It is not moved or changed unless you ask for that.

## Finding something later

Earlier conversations stay in the left sidebar, and each one remembers the files it touched. Search a conversation for the file name, or open the folder directly — the result is an ordinary file on your computer.
