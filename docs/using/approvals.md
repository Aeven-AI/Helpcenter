# What Aeven asks first

Aeven can read files, run commands, open pages, and change things in your connected apps. Before anything of consequence, it asks. The question names the action in plain words, so you can judge it.

## Answering

| Choice | What it does |
| --- | --- |
| Allow once | This action runs now. Aeven asks again next time. |
| Allow for this task | The action may repeat while this task runs. |
| Don't allow | The action does not run, and Aeven is told so it can find another way. |

If a question is unclear, ask in the conversation before answering — "what does that command do?" is a reasonable reply.

## How often it asks

**Settings → General** holds the permission setting. Stricter settings ask more often and are the right default while you are getting used to what Aeven does. A looser setting lets a long task run without interruption.

## When you are unsure

Nothing is lost by saying no. Aeven continues with what it is allowed to do and tells you what it could not finish.
