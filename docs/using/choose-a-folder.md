# Choose a folder

Aeven works in a folder you choose, not in your whole computer. The folder is the boundary: the files it may read and change, and the place results appear.

## Choose one

1. Select the folder control on the conversation screen.
2. Pick the folder that holds the work — a project, a set of documents, a client's files.
3. Ask for what you want in the conversation box.

Pick the folder before you ask, so Aeven reads the right files.

## What the folder means

- Files inside it can be read while Aeven works.
- Files Aeven creates or changes land there.
- Anything outside it is out of reach unless you allow otherwise.

## Change folders

Choose the folder control again and pick another folder. The conversation stays; the files Aeven can see change.
