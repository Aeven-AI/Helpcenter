# The sidebar

The left sidebar is where your work is kept: the folders you have opened, and the conversations you have had in them. Everything else in Aeven is opened from here.

## Workspaces and sessions

A **workspace** is a folder you chose, listed by name. Under it sit its **sessions** — the conversations that happened in that folder, newest first.

- **New Session** starts a conversation in the selected workspace.
- **Add workspace** opens the folder picker and adds another folder to the list.
- A conversation that was not started in a folder sits under **Ungrouped**.

Right-click a workspace to rename it, link a different folder to it, or delete it. Deleting removes it from the list; the folder and its session logs stay on disk, and its sessions are archived.

## Group by

**View options → Group by** decides what the list is grouped on:

| Setting | The list shows |
| --- | --- |
| By workspace | One group per workspace — the folder each conversation belongs to. The default |
| By status | Groups by where a conversation stands rather than where it happened, with everything that has no status collected under **Ungrouped** |

By workspace answers "where was I working"; by status answers "what is still open". Switch between them whenever the other question is the one you have — nothing moves or is renamed, only the grouping changes.

## Order by

**View options → Order by** decides the order inside each group: **Last updated**, the default, or **Manual**, where you arrange sessions yourself by dragging them and the arrangement stays as you left it.

## Show

- **Show archived** adds the **Archived conversations** group to the list. Archived sessions keep their history and can be unarchived from their menu; archiving is how you clear the list without deleting anything.
- **Show automations** decides whether your [bots](/docs/automation/automations) appear as rows among the sessions.

## Search

The field at the top searches your conversations. Typing matches session names immediately; content search looks inside them as well, and needs **Session search** switched on in **Settings → Plugin settings**.

Results say which they are: when content search is off, or could not complete, Aeven says so and shows name matches only. A very broad query returns the first results and asks you to narrow it rather than pretending it showed everything.

## The session menu

Right-click a session for **Rename**, **Fork session**, **Archive session** and, on an archived one, **Unarchive session**. Forking copies a conversation up to now into a new session, so you can try a different direction without losing the original. [Where your work lands](/docs/using/where-your-work-lands)
