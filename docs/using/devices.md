# Phones and simulators

When the work is a mobile screen, Aeven can drive one. It runs the simulators and emulators already installed on your computer, streams the screen into the app, and controls it the way you would.

## Opening one

Choose **Devices** in the sidebar and pick from the list — **iOS Simulators** and **Android Emulators** are listed separately, with the version each one runs. Picking one starts it if it is not running, and the screen appears beside the conversation.

The first time, Aeven installs the device support it needs; that takes a little longer than later openings.

## Using it

| Control | What it does |
| --- | --- |
| Home, Back, Recents | The device's own navigation |
| Rotate | Turns the screen |
| Power off | Shuts the device down |
| Your keyboard and pointer | Typing, tapping, scrolling and dragging inside the app |

Ask in the conversation while the device is open — "open the settings screen and turn on notifications", "what is on screen now" — and Aeven works the device for you, with the same approvals as any other action.

## Taking something away

Ask for a screenshot and it arrives in the conversation as an image, ready to attach to a message or drop into a document. [Chat and attachments](/docs/using/chat-and-attachments)

## When no device appears

- **No simulators or emulators were found** — none are installed. On macOS, install a simulator runtime in Xcode; on Windows, create a virtual device in Android Studio's Device Manager, then **Refresh devices**.
- **The device hub failed to start** — close the panel and open it again. If it keeps failing, quit Aeven completely and start it again.
- **A black screen or a dropped stream** — **Reconnect**. The device keeps its state.
