# Automations

An automation is a task you set up once that runs again on a schedule, without you starting it.

## What one looks like

Every automation has three parts:

- **What to do** — the request, written the way you would write it in a conversation.
- **When** — how often it runs: every morning, every hour, on a particular weekday.
- **Where** — the folder it works in, and any connected account it may use.

When it runs, it starts a conversation of its own, does the work, and leaves the result where you would expect it. You can open that run and read what happened.

## Create one

1. Open **Automations** in the sidebar.
2. Describe the task, choose the folder, and set the schedule.
3. Save it. The next run happens at the scheduled time; the list shows the last and next run.

## Keeping it running

Automations run while Aeven is running. With **Run in the background** on — the default — closing the window does not stop them; quitting Aeven does. A computer that is asleep at the scheduled time runs the task when it wakes.

## Pausing, changing, and removing

Open the automation to pause it, change its schedule or its request, or delete it. Pausing keeps the history; deleting removes the automation and leaves files it already produced.
