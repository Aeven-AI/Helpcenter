# Your first task

The best first task is one you would otherwise do by hand in the next hour: a summary of a document, a comparison of two proposals, a tidy-up of a folder, a draft reply.

## Ask in your own words

Once a folder is chosen, type what you want and press Enter. You do not need special syntax, and you do not need to explain what software to use. For example:

> Read the three proposals in this folder, tell me where they disagree on pricing, and write a one-page summary.

> Find every invoice in the last quarter and put the totals in a table.

## Watch what it does

Aeven works step by step and shows the steps in the conversation. Each step names the file it reads, the command it runs, or the app it looks in. You can stop at any point.

When Aeven needs your decision, it asks in the conversation — to allow an action, to pick between options, or to confirm a detail it could not work out. [How approvals work](/docs/using/approvals).

## Know when it is done

A task is finished when Aeven says so in the conversation and the result is in front of you: the summary in the reply, the file in the folder, the table in the answer. Long tasks also report progress in the conversation, so you can leave and come back.

## If the answer is not what you wanted

Say so in plain words — "shorter", "that is the wrong folder", "use the second document" — and Aeven continues from there rather than starting again. You do not need to repeat the original request.
