# Install and sign in

Aeven runs as a desktop application on macOS, Windows, and Linux. The application opens straight into a conversation; there is no setup screen to work through.

## Install the app

1. Download the installer for your computer from [aeven.io](https://aeven.io).
2. Open the installer and finish it the way you finish any application on your system.
3. Start **Aeven**. A window opens on the conversation screen.

The first launch takes a few seconds while Aeven starts its local service. If the window seems empty at first, it is still starting.

## Or use Aeven Web

Aeven also runs in a browser at [chat.aeven.io](https://chat.aeven.io), with nothing to install. Sign in with the same account and your conversations, memory and settings are there. It is the quick way in, but it does less than the desktop app; for serious work, install the app.

On Aeven Web the assistant works on our servers instead of your computer: it keeps files in your account folder (up to 5 GB), runs commands in an isolated sandbox that can reach the internet, and works in your own browser through the [Aeven extension](/docs/using/browser#in-your-own-browser). It cannot open folders, terminals or programs on your computer; use the desktop app for that, and [move a conversation to your computer](/docs/account/your-data#on-your-other-devices) when it needs them. [Privacy Policy](/docs/privacy) says what Aeven Web stores.

| | Desktop app | Aeven Web |
| --- | --- | --- |
| Your folders and files | Yes | Files in your account folder only |
| Commands and the terminal | On your computer | In a sandbox on our servers |
| Your own browser tabs | Yes, through the extension | Yes, through the extension |
| Browser beside the conversation | Yes | No |
| Apps on your computer, phones and simulators | Yes | No |
| Connectors, memory, skills, images, video and Motion films | Yes | Yes |
| Bots | All of them | Those that need nothing from your computer |

## Sign in

Choose **Sign in** and continue with the account you already use — Google, Apple, or X. Aeven opens a separate window for that provider, then returns to the app.

You stay signed in on that computer. Signing out from the account menu ends the session; the next sign-in asks the provider again.

## What the first screen means

![A new session in Aeven: the Æven mark, a greeting, and the composer at the bottom](/img/app/new-session.png)

*A new session. The composer is the whole first screen: one box, and Aeven waits.*

| Part of the screen | What it is for |
| --- | --- |
| The conversation area | Where you type what you want and read what Aeven does |
| The folder control | Which folder of your computer Aeven may work in |
| The left sidebar | Your earlier conversations and the files in the current folder |
| The right sidebar | The browser, files, and terminal that Aeven opens while it works |
| The account menu | Your plan, credits, settings, and sign-out |

The folder control shows which folder Aeven is working in. [Choose a folder](/docs/using/choose-a-folder) is the next step.

## Updating

Aeven checks for a new version shortly after launch and every 30 minutes after that. When a new version is ready it downloads in the background and installs when you quit. The application menu's **Check for Updates…** reports what it found.

## Running in the background

**Settings → General → Run in the background** is on by default. Closing the last window leaves Aeven running, so work in progress and [bots](/docs/automation/automations) keep going. Quit from the application menu or the menu bar icon to stop it completely.
