# Connect an account

Connecting an account lets Aeven read and act inside it as part of a task: a mailbox, a calendar, a repository, a team chat.

## Connect

1. Open **Settings → Integrations**.
2. Choose the service.
3. Sign in to it in the window that opens and approve the access it asks for.
4. The row turns into a connected account, showing which account is linked.

## What each connection adds

| Service | What Aeven can do with it |
| --- | --- |
| Google | Mail, calendar, and files in your Google account |
| Microsoft | Mail and calendar in your Microsoft account |
| GitHub | Issues, pull requests, and repository contents |
| Slack | Read channels you can see, and post where you allow it |
| Discord | Read channels and servers you belong to, and post |
| Telegram | Read and send messages in your chats |
| WhatsApp | Read and send messages in your chats |
| Email accounts | Read and search mail in the accounts you add |

A connected account is available to every conversation. Ask for what you want — "summarise today's mail", "what is on my calendar tomorrow" — and Aeven uses the right connection.

## Check what it can reach

Each service asks for the narrowest access that makes the feature work, and the consent screen lists it. If a service you need is missing from the list, it is not available on your account.

## Remove access

Open **Settings → Integrations**, choose the account, and remove it. Aeven keeps no further access, and the next task that needs that service has to ask you again. You can also revoke access from the provider's own security page; the row then shows the account as needing to be linked again.
