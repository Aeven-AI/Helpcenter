# 选一个文件夹

Aeven 在你选定的一个文件夹里工作，而不是在你的整台电脑上。文件夹就是边界：它能读和能改哪些文件，以及结果出现在哪里。

## 选一个

1. 在对话界面上选择文件夹控件。
2. 挑那个存着这项工作的文件夹——一个项目、一批文档、某个客户的文件。
3. 在对话框里说出你想要什么。

先选文件夹再提问，这样 Aeven 读到的就是对的文件。

## 这个文件夹意味着什么

- 里面的文件在 Aeven 工作期间可以被读取。
- Aeven 创建或改动的文件落在那里。
- 它之外的东西都够不着，除非你另外允许。

## 更换文件夹

再选一次文件夹控件，挑另一个文件夹。对话留着；Aeven 能看到的文件变了。
