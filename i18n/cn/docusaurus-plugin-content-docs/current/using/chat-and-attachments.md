# 对话与附件

对话是每个任务开始的地方。你也可以把材料交给 Aeven，而不是去描述它。

## 附上一个文件

在发送之前把文件加进消息。Aeven 会读你附上的东西，并把它当作这次请求的一部分——一张要分析的表格、一份要总结的合同、一张出错的截图。

消息框左边那个 **+** 控件，就是一条消息在文字之外还能带上点别的东西的地方：

![输入框里的添加菜单：File、Camera、Goal、Plan、Feedback](/img/app/composer-add.png)

*一个菜单管住所有不是纯文本的东西。*

| 项目 | 它加进来什么 |
| --- | --- |
| File | 来自你电脑的一个文件，附在这条消息上 |
| Camera | 现在拍的一张照片，而不是你手上已经有的文件 |
| Goal | 一个长期目标，Aeven 会跨多条消息一直做下去 |
| Plan | 先把步骤要回来，再动手 |
| Feedback | 就 Aeven 本身跟我们说点什么，而不用离开手头的任务 |

PDF、图片、Office 文档和纯文本会被直接读取。非常大的文件和长视频要更久，而且可能会分段读取。

## 加一张截图

截图常常比一段描述更快，尤其是屏幕上的问题。把它附上，然后说你想拿它做什么。

## 用说话代替打字

用消息框里的麦克风控件把你的请求说出来。文字会出现在框里，这样你可以在发送前改。

## 在同一段对话里接着说

一段对话留着它的上下文：后面的话会指向前面的内容，所以“弄短一点”或者“另一个文件也照样来一遍”不用你重说也能接上。主题变了就开一段新对话；一段新对话比一段又长又杂的对话更快，也更不容易糊涂。
