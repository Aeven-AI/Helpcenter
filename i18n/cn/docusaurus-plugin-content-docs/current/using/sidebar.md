# 侧边栏

左侧边栏是你的工作存放的地方：你打开过的文件夹，以及你在这些文件夹里有过的对话。Aeven 里其他一切东西都从这里打开。

## 工作区与会话

一个**工作区**是你选定过的一个文件夹，按名称列出。它的下面是它的**会话**——在这个文件夹里发生过的对话，最新的在前。

- **New Session** 在选中的工作区里开始一段对话。
- **Add workspace** 打开文件夹选择器，把另一个文件夹加进列表。
- 没有在某个文件夹里开始的对话，归在 **Ungrouped** 下面。

右键一个工作区，可以重命名它、给它关联另一个文件夹，或者删除它。删除只是把它从列表里拿走；文件夹和它的会话日志仍留在磁盘上，它的会话会被归档。

## 分组方式

**View options → Group by** 决定列表按什么分组：

| 设置 | 列表显示 |
| --- | --- |
| By workspace | 每个工作区一组——也就是每段对话所属的那个文件夹。默认 |
| By status | 按一段对话处在什么状态分组，而不是按它发生在哪里，所有没有状态的都收在 **Ungrouped** 下面 |

按工作区分组回答的是“我当时在哪儿干活”；按状态分组回答的是“还开着的是什么”。当要问的是另一个问题时，就在两者之间切换——什么都不会移动或者改名，变的只是分组方式。

## 排序方式

**View options → Order by** 决定每个分组内部的顺序：**Last updated**，也就是默认，或者 **Manual**，在后者里你自己拖动来安排会话，排好了就保持你留下的样子。

## 显示

- **Show archived** 把 **Archived conversations** 分组加进列表。已归档的会话保留它们的历史，可以从它们的菜单里取消归档；归档是你清空列表而不删掉任何东西的方式。
- **Show automations** 决定你的 [bots](../automation/automations.md) 是否作为行出现在会话当中。

## 搜索

顶部那个输入框搜索你的对话。输入时会立刻匹配会话名称；内容搜索还会查看对话里面，需要在 **Settings → Plugin settings** 里打开 **Session search**。

结果会说明自己是哪一种：当内容搜索关着，或者没能做完时，Aeven 会说出来，并只显示名称匹配的部分。一个非常宽泛的查询会返回最前面的结果，并请你把范围收窄，而不是假装它已经把全部显示出来了。

## 会话菜单

右键一个会话，可以看到 **Rename**、**Fork session**、**Archive session**，在已归档的会话上还有 **Unarchive session**。Fork 会把一段对话到此刻为止的内容复制成一个新会话，这样你可以试另一个方向而不丢掉原来的。[你的成果落在哪里](../using/where-your-work-lands.md)
