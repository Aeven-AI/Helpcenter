# 在 Aeven Web 上使用你的桌面设备

[chat.aeven.io](https://chat.aeven.io) 在我们的服务器上、在沙箱里工作。保持 Aeven 桌面应用打开并登录，你在网页上输入的对话就会改在你的电脑上运行：Aeven 可以使用你的文件夹、你的应用、电脑操控和对话旁边的浏览器，在任何浏览器里都行，包括手机。无需任何设置。这也正是 Æven 里的 Æ 所代表的：**Almost Everywhere**（几乎无处不在）。

## 在哪里运行

| 情况 | Aeven 在哪里回答 |
| --- | --- |
| 新对话，且你有一台桌面设备开着 | 你最近使用的那台桌面设备 |
| 最近一次在某台开着的桌面设备上运行的对话 | 那台桌面设备 |
| 没有桌面设备开着 | Aeven Cloud，即我们服务器上的沙箱 |
| 桌面设备大约十秒内没有接手消息 | Aeven Cloud，这样你不会白等 |

回答会边写边出现在网页里，和在桌面应用里一样。Aeven 做出的文件留在做出它们的那台电脑上。

## 选择桌面设备

点对话顶部的 **选项**，再选 **选择桌面设备**。列表显示你账户的每台桌面设备、它是 **在线** 还是最后在线的时间，对话正在运行的那台旁边有一个显示器标记。

- **点一台桌面设备**，对话之后的消息就在那里运行。
- **再点一次带标记的桌面设备** 即取消选择：在网页上，对话回到 Aeven Cloud 运行。
- **离线的桌面设备** 不能选择。点它会说明设备开启后才能选择，在此之前对话继续在 Aeven Cloud 中运行。

Aeven 正在回答时这些都用不了；等回答结束再选。

## 在桌面应用里

账户里有多台桌面设备时，桌面应用的 **选项** 里也有 **选择桌面设备**。**这台电脑** 排在列表最前，后面是其他桌面设备。选另一台桌面设备后，只要它开着，这段对话从每台设备上都会在那里运行——这台电脑、网页和你的其他桌面设备。选 **这台电脑** 即可把它收回。

## 关闭桌面设备

退出桌面应用后，它会立即显示为离线，新对话会直接交给 Aeven Cloud。断开连接的桌面设备或进入睡眠的笔记本，大约两分半钟内会显示为离线。旧版桌面应用不会报告自己开着，因此总是显示为离线；更新后才能选择它。

## 同一网络里的桌面设备

你账户的两台桌面设备在同一网络，或在同一 Tailscale 网络里时，会直接互相连接。对话、设置和消息无需经过互联网就能到达另一台桌面设备，更快，而且断网时也能继续。每台桌面设备在连接前都会证明自己属于你的账户。
