# 录音机

录音机会在会议进行时把内容记下来：你对着麦克风说的话，以及其他人通过你的电脑说的话——无论是 Zoom、Google Meet、Teams 或其他应用里的通话，还是浏览器里正在播放的视频。没有人会加入通话；Aeven 在你自己的电脑上收听。

录音机是桌面版的一部分，支持 macOS、Windows 和 Linux。在 Aeven Web中选择它，会提示你在桌面版中继续。[在 Aeven Web 上使用你的桌面设备](/docs/using/desktop-from-web)

## 打开它

打开右侧边栏，选择 **录音机**。一个对话只有一个录音机；再次选择它会回到已经打开的那一个。

第一次使用时，Aeven 会下载区分声音所需的内容，录音机顶部会显示进度条。只需几秒，而且只下载一次。

## 录制

选择 **开始录制**。第一次录制会请求两项权限：

- **麦克风**——用于记录你说的话。
- **系统音频录制**（macOS）——用于记录电脑播放的声音，Aeven 正是这样听到通话中的其他人。

录制时，录音机会显示时长、**你** 和 **其他人** 各自的音量，以及正在写出的转录，每次几句话：

| 标签 | 是谁 |
| --- | --- |
| 你 | 你的麦克风 |
| 发言人 1、发言人 2…… | 其他人的声音，按第一次开口的顺序编号 |

下方的按钮可以把目前的转录添加到对话、停止录制，或放弃这段录音。

Aeven 会根据开头的一段语音判断会议的语言并保持使用它；在确定之前写出的句子会被更正。切换对话时录制会继续，关闭录音机则会停止录制。

## 录制结束后

选择 **停止录制**。Aeven 会写完最后几句，然后转录留在录音机中，下方有三个按钮：**复制**、**新录音** 和 **添加到聊天**。最后一个会把转录放进输入框，方便你接着提问——“总结一下”、“列出待办事项”、“起草跟进邮件”。[对话与附件](/docs/using/chat-and-attachments)

## 已保存的录音

有人说话的录音会在结束时自动保存，转录和音频一起保存；时长旁边会显示 **已保存**。放弃的录音或没有人说话的录音不会保留。

录音机底部的列表按钮会打开你的录音，最新的在最前。打开一段录音，可以：

- 播放音频，
- 阅读转录，
- 重命名——点击标题直接输入，
- 复制或添加到对话，
- 删除——这会在你的所有设备上删除转录和音频。

你的录音跟随你的账户：转录会出现在你登录的每台电脑上，音频也会同步到你的其他电脑，传输途中始终加密。在音频到达之前，在另一台电脑上打开的录音会说明这一点，并显示转录。

## 转录

录音机使用与语音输入相同的语音模型。在 **设置 → 通用设置 → 语音输入** 中选择：在你自己的电脑上转录，音频不会离开电脑；或者通过 Aeven 转录。如果录音机提示语音输入已关闭或尚未就绪，**打开语音设置** 会带你过去。

## 录制之前

通话中的其他人不会被告知 Aeven 正在转录。在你所在的地方，录制对话可能需要所有人同意——开始之前请先说明你在做记录。

## 缺少某些内容时

- **无法获取电脑音频**——只会转录你的麦克风。在 macOS 上需要 macOS 14.2 或更高版本，并在 **系统设置 → 隐私与安全性** 中允许 Aeven 进行 **系统音频录制**。
- **你的声音出现了两次**——扬声器的音量大到麦克风收进了通话声音。戴上耳机即可解决。
- **所有人都是同一个发言人，或者一个人变成了两个**——声音相近或非常简短的插话可能会被标错。较长的发言会被可靠地标注。
- **没有发言人编号，只有“其他人”**——这台电脑上无法区分声音（Windows on ARM），或者相关内容还没下载完；请查看录音机顶部。
