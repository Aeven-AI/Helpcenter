# Aeven 会记住什么

Aeven 在对话之间留下有用的知识，这样你不用一遍遍重复自己。其余的，就留在它发生的地方。

## 三种记忆

| 类型 | 它装着什么 | 它住在哪儿 |
| --- | --- | --- |
| 对话 | 你说了什么，以及 Aeven 在这个任务里做了什么 | 那段对话自己的历史 |
| 记忆 | 关于你、你的项目和你想怎么干活的长久事实与偏好 | **Settings → Memory** |
| 学到的做法 | 以前奏效过、值得再来一遍的做法 | **Settings → Memory** |

一段对话不会自动变成记忆。你告诉 Aeven 的关于你自己的事，或者它学到、下个星期仍然成立的事，才会。

## 谁能读到它

记忆属于你的账号，所以你在每一台登录过的设备上都能看到它。Aeven 不读它：Aeven 没有人会打开你的记忆，对存放同步副本的系统的访问只限于运行这个服务的人，而且会被记录下来。

让各设备保持同步的那份副本是加密的，端到端保护——密钥留在你自己的设备上——正在逐步铺开。[你的数据](../account/your-data.md) 说了每一份副本住在哪儿；[隐私政策](../legal/privacy.md) 说了什么会离开你的电脑。

## 改它

打开 **Settings → Memory**，可以读已经存下的内容、改掉写错的一行，或者删掉一条你不想再用的。改动从下一段对话起生效；当前这一段保留它自己的上下文。

## 你自己立下的指令

**Settings → Personalisation** 里放着你亲手写的长期指令：你喜欢什么样的回答、要避开什么、什么必须每次都做。这些对每一段对话都生效，并且压过 Aeven 自己推断出来的东西。

## 它不做什么

Aeven 不会顺手就记住。如果有什么该留下来，就说出来——“记住这个客户喜欢短一点的更新”——之后再去记忆里核对一下。
