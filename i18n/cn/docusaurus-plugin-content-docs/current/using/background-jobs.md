# 持续运行的工作

一个任务很少只有一步。Aeven 会运行命令，把一部分工作交给帮手代理，把若干步骤串成工作流——这些都不必让对话停下来。**Jobs** 列表显示此刻正在运行什么，以及刚刚结束什么。

## 那里会出现什么

| 种类 | 是什么 |
| --- | --- |
| Bash | 在你电脑上运行的一条命令 |
| PowerShell | 在 Windows 上做同样的事 |
| Subagent | 一个独自处理任务中某一部分的帮手代理 |
| Workflow | 几个帮手一起走过各个阶段 |

每一行是一个任务。展开它，可以看到它运行的命令、目前的输出、进度，以及结束后它的结果。

## 看着它运行

正在运行的任务会显示已经跑了多久。它运行期间，你可以继续提问、打开另一个对话，或者干脆不管它——任务会把结果回报给发起它的那个对话，结果本来就该在那里。

## 停止一个任务

**Stop job** 会立即结束它。被停止的任务无法接着跑；再要一次这项工作，它会从头开始。Aeven 会请你确认，因为一条做到一半的命令可能留下东西。

## 完成之后

列表会保留已完成的任务和它们的结果：**Done**、**Stopped** 或 **Failed**，各自用了多久，以及什么时候。**Clear** 会清空已完成的部分；它们所属的对话不受影响。
