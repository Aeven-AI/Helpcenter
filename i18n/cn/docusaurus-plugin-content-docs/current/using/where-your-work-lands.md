# 你的成果落在哪里

Aeven 把结果放在你接着就能用的地方：对话里、它正在干活的文件夹里，或者一个你可以在旁边打开的预览里。

## 在对话里

回答以文字的形式过来：一段摘要、一张表格、一份计划、一段解释。想拿到别处去用，就从回复里复制。

## 在你的文件夹里

当一个任务产出一个文件——一份文档、一张表格、一个脚本、一组改了名的图片——Aeven 会把它写进你选定的文件夹，并在对话里说出它的名字。文件侧边栏会随着它的变化显示这个文件夹。

## 在旁边

Aeven 干活的时候，文件、页面和终端会在右侧边栏里打开，这样你看着它在做什么，也不用离开对话。很长的输出在任务做完之后仍然留在那里。

## 你发出去的附件

你附上的东西是作为这次请求的一部分被读的。除非你要求，它不会被移动或者改动。

## 以后再找回来

更早的对话留在左侧边栏，每一段都记得它碰过哪些文件。在一段对话里搜文件名，或者直接打开那个文件夹——结果就是你电脑上的一个普通文件。
