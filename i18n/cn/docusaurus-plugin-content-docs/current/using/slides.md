# 幻灯片与演示文稿

Aeven 会和你一起做演示文稿，用的是你选的设计。打开侧边栏里的 **灵感**，选择 **幻灯片** 标签页；或者在任何对话里直接要一份演示文稿。

## 选一个模板

**幻灯片** 标签页里有 36 个幻灯片模板：Dark Pills、Bauhaus Mono、Lush Lux、Startup Pitch、Magazine、Pixel Quest 等等。点开一个，就能逐页翻看它的全部幻灯片。每个模板都有同样几类幻灯片（标题、议程、要点、数字、时间线、引言、图表、对比、团队、致谢），所以任何演示文稿都能放进任何模板。

## 开始做演示文稿

- 点 **使用模板**，在输入框里把句子补完，写明演示文稿讲什么，然后发送。
- 或者从你已有的资料开始：在 **从您已有的资料开始** 下面 **添加文件**（PowerPoint、Keynote、Pages、PDF 或 Word）。Aeven 会保留它的内容和脉络，用这个模板的设计重新做一遍。

还没想好用哪个模板？在 **幻灯片** 标签页的输入框（**“描述您需要的演示文稿”**）里写，或者在任何对话里说：*“根据这份报告做一份十页的演示文稿”*。

## Aeven 和你一起做

Aeven 会先问几个问题（给谁看、要多长、大家最该记住的那一点），提出一份大纲，然后严格按照模板的设计做出幻灯片。模板里的示例幻灯片只是参照，不是成品：你的内容会替换它们，Aeven 还会加上你的故事需要的东西，比如用你的数字画的图表、示意图、对比，以及你自己的照片和短视频。

想改什么就直接说：*“把第 4 页拆成两页”*、*“把图表改成折线图”*、*“换成 Magazine 模板”*。换模板时每个字都会保留。

## 下载

文件保存在你工作区里的 **presentations** 文件夹中。

| 格式 | 你会得到 |
| --- | --- |
| PDF | 每页幻灯片一页，和设计完全一样 |
| PowerPoint | 可编辑的文字、形状和图片，使用模板的字体，并带上你的演讲者备注。字体随文件一起保存，所以在没有这些字体的电脑上看起来也一样 |
| Keynote | 由 Keynote 从 PowerPoint 文件转换而来，需要在装有桌面版 Aeven 和 Keynote 的 Mac 上 |
| HTML | 用浏览器放映的演示文稿，带有动画和视频 |

制作 Keynote 文件之前，Aeven 会请你批准，因为它要在你的 Mac 上安装模板的字体，并打开 Keynote 来转换。Keynote 文件不会带上字体：要在另一台 Mac 上打开，先在那台 Mac 上安装模板的字体。这些字体都可以在 Google Fonts 免费获取。

## 费用

演示文稿和任何其他请求一样，消耗你套餐里的积分。页数更多的演示文稿，以及你让 Aeven 为它生成的图片，花费更多。[账号、套餐与积分](../account/plans-and-credits.md)
