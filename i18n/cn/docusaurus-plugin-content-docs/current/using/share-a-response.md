# 分享回复

Aeven 给出的任何回答都可以变成一个公开链接：把它发到聊天、邮件或帖子里，打开它的人会在一个单独的页面上读到这条回答。只分享回答本身。你的提问、你的名字和对话的其余部分都不会公开。

## 创建链接

1. 在回答下方的操作栏中选择 **分享**。
2. 对话框打开时会先显示 **链接预览**：链接在微信、WhatsApp、iMessage、Slack 等应用里展示的卡片。它需要片刻才会出现。
3. 选择 **创建链接**。生成链接时按钮里会转动一个加载图标，完成后链接会自动复制，可以直接粘贴。在手机或平板上，会改为打开设备的分享面板。

链接也会显示在对话框里，旁边的 **复制链接** 可以再次复制。

再次分享同一条回答不会生成第二个链接，而是更新你已有链接背后的页面，因此修正后的回答会送达所有拿到链接的人。

## 页面显示什么

| 会分享 | 不会分享 |
| --- | --- |
| 回答的文字和格式 | 你的提问 |
| 回答中的图片，最多八张 | 你的名字和账户 |
| | 对话的其余部分 |
| | 图片以外的文件 |

页面上有一个通往 Aeven 的按钮：没有账户的人看到 **试用 Æven**，已登录的人看到 **前往 Æven**。

当一轮回答包含多个步骤时，链接带的是最终回答，与 **复制** 取用的文本相同。

## 管理你的链接

在分享对话框中选择 **管理**。**已创建的链接** 按从新到旧列出你账户创建的每个链接；向下滚动会加载更早的链接。

- **打开**：选择链接旁的箭头标记，查看别人看到的页面。
- **删除**：选择链接旁的垃圾桶删除单个链接。它会立即失效，打开它的人会看到链接已不存在。
- **删除所有链接**：确认后删除全部链接。此操作无法撤销。

你的链接属于你的 Aeven 账户，而不是某台设备：桌面应用和 [chat.aeven.io](https://chat.aeven.io) 上的列表是同一份。

## 须知

- **需要登录。** 链接由你的 Aeven 账户创建和保存。
- **已删除的链接可能仍留在预览里。** 聊天应用和社交网站会保留它们已经抓取的卡片，所以页面删除后旧预览可能仍会显示。
- **每个账户最多 5,000 个链接。** 删除一些即可腾出空间。
- **很长的回答** 可能太大而无法分享，对话框会提示。
