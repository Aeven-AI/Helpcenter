# Æven 会先问什么

Æven 能读文件、运行命令、打开页面，也能改动你连着的应用里的东西。凡是有点后果的事，它都先问。问题里会用直白的说法点明这个动作，好让你自己判断。

## 怎么回答

| 选项 | 它做什么 |
| --- | --- |
| 允许一次 | 这个动作现在就执行。下次 Æven 还会再问。 |
| 本会话允许 | 在这段对话里，这个动作可以反复执行，不再询问。 |
| 拒绝 | 这个动作不执行，而且 Æven 会被告知这一点，好让它另找办法。 |

如果一个地方你没看明白，回答之前先在这段对话里问一句——“那条命令是干什么的？”就是一句合理的回复。

## 它多久问一次

**设置 → 通用设置** 里放着权限设置。越严格的设置问得越勤，在你还没习惯 Æven 会做什么的时候，这是合适的默认。更宽松的设置让一个长任务不被打断地跑完。

## 拿不准的时候

说“不”不会损失什么。Æven 照着允许它做的事接着干，并告诉你哪些它没能做完。
