# 浏览器

Aeven 可以替你打开网站、阅读网页，并在上面点击和输入。整个过程你都看得到：Aeven 动手之前，指针会先移到每个链接、按钮和输入框上。

## 在侧边栏里

让 Aeven 打开一个网站——“打开 linkedin”“在他们网站上查一下营业时间”——它就会在右侧边栏的 **Browser** 里打开。每个 **Browser** 胶囊就是一个标签页；Aeven 可以打开不止一个，并用指针在它们之间切换。

- 工具栏你和 Aeven 都能用：后退、前进、刷新、复制截图，以及 **More** 菜单里的缩放、外观和在 Chrome 中打开页面。
- 遇到该你来做的步骤——登录、验证码、确认付款——Aeven 会显示一条简短的说明，告诉你要做什么，然后等你。它从不输入你的密码。
- Aeven 在读取你的剪贴板、搜索你访问过的页面、清除 cookie，或使用网站提供给助手的工具之前，都会先问你。

## 在你自己的浏览器里

**Aeven 扩展**让 Aeven 在你平时用的浏览器里工作，沿用你已经登录的网站。

1. 在 Chrome、Brave 或 Edge 中，从 [Chrome 网上应用店](https://chromewebstore.google.com/detail/cpgmlafibkmklfnpjpjbdgoegpljfofa)安装 **Aeven**。
2. 使用 Aeven 时保持该浏览器打开。**设置 → 通用 → 浏览器扩展**会显示哪些浏览器已连接。

然后让 Aeven “在我的浏览器里”做某件事。它会在一个名为 **Aeven** 的标签组里打开自己的标签页，放在前台让你看着，并且只在这些标签页里工作；你的其他标签页从不被读取。经你同意，它还可以搜索你的浏览历史和书签。

Aeven 在某个标签页里操作时，浏览器会显示“Aeven 已开始调试此浏览器”。这是浏览器在告诉你有扩展正在控制一个标签页；Aeven 停下几秒后，这条提示就会消失。

| 你在哪里使用 Aeven | 扩展如何连接 |
| --- | --- |
| 桌面应用 | 通过同一台电脑上的应用。可以同时连接多个浏览器；需要时如果没有浏览器在运行，Aeven 会自己打开浏览器。 |
| Aeven Web | 通过你在同一个浏览器里打开着的 [chat.aeven.io](https://chat.aeven.io) 页面。 |

在 Aeven Web 上，扩展是 Aeven 唯一能用的浏览器，所以“打开 linkedin”会在你浏览器的新标签页中打开该网站。如果 Aeven 需要时扩展缺失，会出现标题为 **让 Aeven 使用你的浏览器** 的窗口，提供 **添加到 Chrome**（Edge 和 Brave 会显示各自的名字）。在打开的标签页中添加扩展后回来：Aeven 会自己发现它并继续，无需重新加载页面。如果你用的时间比 Aeven 等待的更长，扩展添加后窗口会显示 **继续**。**暂不** 会让 Aeven 不使用你的浏览器完成任务。Safari、Firefox 和手机浏览器无法添加扩展；请在电脑上的 Chrome、Edge 或 Brave 中打开 Aeven Web，或使用桌面应用。

在 Aeven Web 上，在右侧边栏选择 **浏览器**，会通过扩展在你的浏览器中打开一个新标签页，放在 Aeven 的标签页分组里。没有扩展时，则会提示你在桌面应用中继续。[在 Aeven Web 上使用你的桌面设备](/docs/using/desktop-from-web)
