# 选一个模型

Aeven 不绑在一个 AI 模型上。模型是读你的请求、写出回答的引擎；Aeven 决定怎么围着它安排自己，你来决定哪一个回答。

## 从 Aeven 模型开始

Aeven 模型跟着应用一起来，不用任何设置：登录之后就能回答，用多少由你套餐里的额度付。它们是推荐的默认——它们照着 Aeven 的干活方式调过，连它的工具、审批和长对话都算在内，所以一个要用好几步、好几个文件的任务，表现会和这几页其余地方说的一样。

如果你要的就只是 Aeven 的模型，这一页的下一节你永远不用打开。

## 这个选择在哪儿

模型是在消息框里设的，不在某个设置界面里——它属于你正要问的那件事。那个控件显示眼下回答的是哪个模型：

![输入框里的模型控件，已展开：Model 和 Effort](/img/app/model-menu.png)

*Model，以及它该想多深。*

- **Model** 挑谁来回答。改动从你的下一条消息起生效；一段已经开始的对话会留着它自己的模型，直到你在那儿改。
- **Effort** 是模型在回答之前花多少推理。越高越慢，难题上更好；越低越快，适合小问题。

**Settings → Models** 是连接模型而不是挑模型的地方：你自己的 key、一个端点，或者一个本地地址，都如下面说的。

回答的模型名字在对话里看得见，所以一个你喜欢的结果是哪个模型给的，你能分得出来。

## 你自己的提供商

用你自己的 key 是跑 Aeven 的一种正经方式，不是将就。如果你的账号是用你自己的 API key、一个兼容 OpenAI 的端点，或者你在别处订阅的某个模型配好的，**Settings → Models** 收下那个 key 或者地址，还有模型的名字。保存就够了，不用重启。

在你自己的机器上跑模型也算你自己的提供商：把 Aeven 指到它的本地地址，它就从那儿回答。对话、记忆和连接都留在原处——它们属于 Aeven，不属于模型。

## 当一个模型用不了

失败的消息通常会说出原因：key 过期了、到了套餐上限，或者服务中断。[修好一个问题](../help/troubleshooting.md) 列出了常见的情况和该怎么办。
