# 机器人

机器人是一个会自行重复运行的任务：晨间简报、收件箱分拣、会议准备、每周汇总、对你关心的某个页面的检查。你用文字描述一次；它按计划或在某件事发生时被唤醒，留下一个带着结果的对话，并告诉你上次什么时候跑过、下次什么时候跑。

## 创建一个

在侧边栏打开 **Bots**。这个页面列出你的机器人、你的看板和 **想法**；底部的输入框写着 **描述一个新Bot**。挑一个想法——它会填进输入框，你可以先改再发送——或者自己描述这套例程：*“每个工作日早上，给我今天的日程和需要我处理的邮件做个简报”*。

其余的事 Æven 用一段简短对话完成：它问清缺的信息（哪个文件夹、哪个账户、几点、哪个时区），然后展示 **任务**、什么会 **唤醒** 它、它可以用的 **连接器**，以及它打算使用的 **权限**。在你确认之前什么都不会保存，而且你可以在那段对话里先改其中任何一项，然后再确认。

**想法** 是你可以调整的现成请求，分为按角色、开启一天、规划一周、掌握动态、工作与财务、日常生活。**按角色** 为营销、销售、客服、招聘、财务、幕僚长、工程和内容创作者各准备了一个现成的机器人。**为你推荐** 会根据 Æven 已了解的你的工作和习惯推荐机器人；如果可用的记忆太少，它会先问几个问题。

有了已连接的账户，机器人能做的事多得多。需要邮件、日历或 GitHub 的想法都做了标记，**连接账户** 会直接把你带到那里。[连接器](../connections/connected-apps.md)

## 什么会唤醒机器人

一个机器人可以有不止一种唤醒方式——比如每周的计划加一个 Webhook。它的卡片会逐一显示。

| 唤醒方式 | 怎么运作 |
| --- | --- |
| 计划 | 在你选定的时间；见下表 |
| 新邮件 | 你添加的邮箱账户收到邮件时，可以只限某个发件人或某个主题。第一次检查只记下已有的邮件 |
| 日历事件 | 每个事件开始前或开始后的某个时间，或正好在开始时。可以只限标题包含某个词、有某个人参加、有或没有外部来宾，或你已接受的事件。支持 Google Calendar、Outlook Calendar 和 Microsoft 365 |
| GitHub 动态 | 某个代码仓库发来事件时——新的 issue、pull request、已发布的 release。可以只限部分事件、部分动作和一个仓库 |
| 外部触发 | 另一个服务带着密钥向机器人的私有地址发请求时 |
| 另一个机器人 | 你给它连接的某个机器人把任务交给它时 |

会议改了时间，机器人就在新的时间被唤醒，同一个会议绝不会唤醒两次。

### 计划

| 你可以选择的计划 | 运行时间 |
| --- | --- |
| 每天某个时间 | 每天在那个时间 |
| 工作日某个时间 | 周一到周五 |
| 每周指定的星期几 | 每周一次 |
| 在某个日期运行一次 | 只运行一次 |
| 每隔若干分钟 | 按这个间隔 |
| 每隔若干小时，在某一分钟 | 与时钟对齐 |
| 在每月选定的日期 | 那些日期 |
| 在每月第一个、第二个、第三个或第四个指定星期几 | 每月的那一天 |
| 每年某个日期 | 每年一次 |
| 自定义计划 | 你自己写的 cron 表达式 |

其中任何一个都可以带结束日期，到期后机器人会自己停下。计划还可以让每次运行最多延后 30 分钟开始——卡片上会写 *最多延后……开始*——这样几个同一分钟到点的机器人不会同时启动。

### 运行期间

如果机器人在一次运行还没结束时又被唤醒，它会做三件事之一，显示在它页面的 **运行期间** 下：新的唤醒 **被跳过**（默认）、**排队等待**，或 **同时运行**。想换一种，在机器人的对话里说就行。

## 一次运行是什么样

每次运行都是一段普通的对话，收在侧边栏的执行记录里（**视图选项 → 显示执行记录**）。读它，看它做了什么，想要更多就在里面回复——一次运行不是一份死掉的日志。

机器人产出的文件留在给它的那个文件夹里。机器人的卡片显示 **下次执行**——没有计划的机器人显示 **被唤醒时**——和 **上次结果**，它的 **执行记录** 列表保留每一次尝试和它到达的结果：

| 状态 | 含义 |
| --- | --- |
| 已排队 | 等待轮到它 |
| 执行中 | 正在工作 |
| 执行已结束 | 做完了，结果在它的对话里 |
| 没有新内容 | 它看过了，没有值得报告的东西 |
| 未完成 | 因为一个错误停下了，或者它报告任务做不了；这次运行会说明原因 |
| 已跳过 | 它没有运行——电脑关着，或者计划已经不再适用 |
| 已停止 | 你把它停了 |

没有新内容的运行不会碍事：**上次结果** 显示最近一次真正做了事的运行，连续几次会折叠成一行，比如 *5 次执行没有新内容*。改动过文件、或遇到了不允许执行的操作的运行，绝不会被记为没有新内容。

当任务这样要求时，机器人还可以自己停下——*“每天早上查一下包裹物流，送到之后就停”*。它的卡片会显示，比如 **已由 08:00 的执行暂停**，按 **恢复** 就能让它重新开始。

## 机器人可以做什么

正是你创建时确认的那些：它在哪个文件夹里工作、可以用哪些连接器、可以采取哪一类操作。

- **它的连接器。** 机器人只使用给它的账户。在这些账户里，它不经询问就会行动——确认机器人时你已经批准了它们——所以一个往 Slack 发消息的机器人就会直接发。其他任何账户都会被拒绝，运行里会说明。
- **其余一切。** 这些权限之外的工作不会做，运行会说明它略过了什么，而不是在凌晨三点来问你。
- **已保存的批准。** 你为某个机器人允许过的操作，会保存在它页面的 **已保存的批准** 下，并写明到期日期——30 天之后。到期后机器人会重新询问。**撤销** 可以立刻收回一项。

所以确认这一步在这里比在任何地方都更重要——要读连接器和权限，不只是读任务。

## 控制一个机器人

在 **Bots** 页面上，每张卡片都有 **立即执行**、**暂停** 或 **恢复**，以及 **更多** 里的 **编辑** 和 **删除**。点开卡片就进入这个机器人自己的页面：它的计划、下次执行、上次结果、完整的任务、执行记录，以及一张 **高级** 卡片。

- **立即执行** —— 立即启动它，不必等唤醒。**停止** 会结束正在进行的运行。
- **暂停** 和 **恢复** —— 停止今后的运行，其他一切保留。
- **编辑** —— 打开机器人的页面和它的输入框，输入框写着 **修改这个Bot…**。只需输入改动——*“改到 7:00，周末不跑”*——Æven 会在保存前给你看新版本。
- **删除** —— 永久停止它。正在进行的运行会做完，它的历史会保留，它已经写下的文件仍留在你的文件夹里。

顶部的 **概览** 和 **执行记录** 在你的机器人和所有机器人的运行之间切换。**清除执行记录** 把已结束的运行从列表里清空，并把它们的对话从侧边栏归档。仍在进行中的运行会保留，清空之后无法撤销。

## 重试一次失败的运行

**重试** 会把同一个任务再运行一次。先读一读失败的那一次：它可能已经在 Æven 之外改动了什么，把同样的步骤跑两遍可能让效果翻倍。

## 从外部启动一个机器人

两者都在机器人的 **高级** 卡片里。

**外部触发。** **创建 Webhook** 会给机器人一个私有地址和一把密钥。任何能带着这把密钥向该地址发请求的东西都会启动一次运行，这让机器人可以从一个表单、一条监控告警或另一个服务触发。把密钥当作密码对待：**更换密钥** 会替换它，并拒绝仍在用旧密钥的请求；**移除 Webhook** 则会拒绝所有请求，直到你创建新的为止。

**GitHub。** 由 GitHub 动态唤醒的机器人会显示一个 **Payload URL** 和一把 **密钥**。在代码仓库的设置里添加一个 Webhook，填入这个 payload URL、内容类型 `application/json` 和这把密钥。创建机器人时说清哪些事件和动作重要——*“当 release 发布时”* 每个 release 只唤醒一次，而不是在发布前每改一次草稿就唤醒一次。

## 看板：协同工作的机器人 {#boards}

看板把互相交接工作、共用一个预算的机器人放在一起——一个研究员把发现交给写手，写手把草稿交给审稿人。

在 **看板** 下选择 **新建看板**。Æven 会问哪些机器人加入、哪个机器人把工作交给哪个、发起方是否等待结果、预算是多少，并在保存前把看板给你看。

- **交接工作。** 机器人只能把任务交给你给它连接的机器人。发起方等待时，结果会作为一次新的运行回到它那里。一个机器人也可以等待多个发起方——等它们都交来任务后才开始，或者第一个交来就开始。
- **预算。** 看板可以限制同时进行的运行数量，以及每天使用的 token 数量。超出的运行会被拒绝，看板会说明是哪个上限挡住了它。
- **最近一条链。** 看板卡片显示最近一条交接链，每一步标为 **等待中**、**运行中**、**已完成**、**未完成**、**已释放** 或 **已拒绝**，并附上它用掉的 token。停止其中一次运行，会停止这条链上其余的运行。

**删除看板** 只删除看板本身；它的机器人会继续各自运行。

## 机器人在哪里运行

每个机器人都显示 **运行位置**。不需要你电脑上任何东西——只用网络和已连接账号——的机器人在 **Æven 云端** 运行，所以你关机时它也照常工作。会用到你的文件、浏览器或应用的机器人在 **你的电脑** 上运行，它的页面会说明它需要其中哪些。

要更改，打开机器人，在 **高级** 里选择 **选择运行位置**。**此Bot的运行位置** 列出 Æven 云端和你的每一台电脑，以及它是否在线、上次在线是什么时候；机器人用不了的位置会说明它需要什么。

## Æven 关闭的时候 {#aeven-关闭的时候}

在你电脑上运行的机器人需要那里的 Æven 开着。在 **Settings → General → Run in the background** 打开时——这是默认设置——关闭窗口不会让它停下；退出则会。到了计划时间电脑正在睡眠的话，它会在唤醒后运行该机器人，而在 Æven 关闭期间到点的计划会在那时补上，而不是丢失。如果你已退出登录，计划会留着，但什么都不会运行，机器人页面会一直这么显示，直到你重新登录。
