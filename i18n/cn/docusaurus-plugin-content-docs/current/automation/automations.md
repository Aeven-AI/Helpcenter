# 机器人

机器人是一个会自行重复运行的任务：晨间简报、收件箱分拣、每周汇总、对你关心的某个页面的检查。你用文字描述一次；它按计划运行，留下一个带着结果的对话，并告诉你上次什么时候跑过、下次什么时候跑。

## 创建一个

在侧边栏打开 **Bots**，选择 **New**。然后挑一个设想，或者直接在输入框里描述这套例程——*“每个工作日早上，给我今天的日程和需要我处理的邮件做个简报”*。

其余的事 Aeven 用一段简短对话完成：它问清缺的信息（哪个文件夹、哪个账户、几点、哪个时区），然后展示它打算使用的 **task**、**schedule** 和 **permissions**。在你确认之前什么都不会保存，而且你可以在那段对话里先改这三项中的任何一项，然后再确认。

**Ideas** 是你可以调整的现成请求，分为开启一天、规划一周、保持关注、工作与金钱、日常生活。**Ideas for you** 会根据 Aeven 已了解的你的工作和习惯推荐机器人；如果可用的记忆太少，它会先问几个问题。

有了已连接的账户，机器人能做的事多得多。需要邮件、日历或 GitHub 的设想都做了标记，**Connect accounts** 会直接把你带到那里。[连接器](../connections/connected-apps.md)

## 它什么时候运行

| 你可以选择的计划 | 运行时间 |
| --- | --- |
| 每天某个时间 | 每天在那个时间 |
| 工作日某个时间 | 周一到周五 |
| 每周指定的星期几 | 每周一次 |
| 在某个日期运行一次 | 只运行一次 |
| 每隔若干分钟 | 按这个间隔 |
| 每隔若干小时，在某一分钟 | 与时钟对齐 |
| 在每月选定的日期 | 那些日期 |
| 在每月第一个、第二个、第三个或第四个指定星期几 | 每月的那一天 |
| 每年某个日期 | 每年一次 |
| 自定义计划 | 你自己写的 cron 表达式 |

其中任何一个都可以带结束日期，到期后机器人会自己停下。

## 一次运行是什么样

每次运行都是一段普通的对话，会在侧边栏里为你打开。读它，看它做了什么，想要更多就在里面回复——一次运行不是一份死掉的日志。

机器人产出的文件留在给它的那个文件夹里。机器人所在的那一行显示 **Next run** 和 **Last result**，它的 **Runs** 列表保留每一次尝试和它到达的结果：

| 状态 | 含义 |
| --- | --- |
| 排队中 | 等待轮到它 |
| 运行中 | 正在工作 |
| 已完成 | 做完了，结果在它的对话里 |
| 未完成 | 因为一个错误停下了；对话里说明了原因 |
| 已跳过 | 它没有运行——电脑关着，或者计划已经不再适用 |
| 已停止 | 你把它停了 |

## 机器人可以做什么

正是你创建时确认的那些：它在哪个文件夹里工作、可以用哪些账户、可以采取哪一类操作。这些权限之外的工作不会做，运行会说明它略过了什么，而不是在凌晨三点来问你。所以确认这一步在这里比在任何地方都更重要——要读权限，不只是读任务。

## 控制一个机器人

打开一个机器人可以：

- **Run now** —— 立即启动它，不必等计划到点。
- **Pause** 和 **Resume** —— 停止今后的运行，其他一切保留。
- **Adjust** —— 修改任务、计划或权限，同样是一段对话，保存前先给你看这次改动。
- **Delete** —— 永久停止它。正在进行的运行会做完，它的历史会保留，它已经写下的文件仍留在你的文件夹里。

**Clear runs** 把已完成的运行从列表里清空，并把它们的对话从侧边栏归档。仍在进行中的运行会保留，清空之后无法撤销。

## 重试一次失败的运行

**Retry** 会把同一个任务再运行一次。先读一读失败的那一次：它可能已经在 Aeven 之外改动了什么，把同样的步骤跑两遍可能让效果翻倍。

## 从外部启动一个机器人

机器人可以带一个**入站触发器**——一个私有地址和一把密钥。任何能带着这把密钥向该地址发请求的东西都会启动一次运行，这让机器人可以从一个表单、一条监控告警或另一个服务触发。把密钥当作密码对待：**New key** 会替换它，并拒绝仍在用旧密钥的请求；移除触发器则会拒绝所有请求，直到你创建新的为止。

## 机器人在哪里运行

每张机器人卡片都显示 **运行位置**。不需要你电脑上任何东西——只用网络和已连接账号——的机器人在 **Aeven 云端** 运行，所以你关机时它也照常工作。会用到你的文件、浏览器或应用的机器人在 **你的电脑** 上运行，卡片会说明它需要其中哪些。想把本可以在云端运行的机器人留在自己电脑上，打开它并选择 **仅在我的电脑上运行**；**允许在 Aeven 云端运行** 可以撤销。

## Aeven 关闭的时候

在你电脑上运行的机器人需要那里的 Aeven 开着。在 **Settings → General → Run in the background** 打开时——这是默认设置——关闭窗口不会让它停下；退出则会。到了计划时间电脑正在睡眠的话，它会在唤醒后运行该机器人，而在 Aeven 关闭期间到点的计划会在那时补上，而不是丢失。如果你已退出登录，计划会留着，但什么都不会运行，机器人页面会一直这么显示，直到你重新登录。
