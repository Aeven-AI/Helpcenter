# Aeven 能做的一切

Aeven 是一个助手，却有很多双手。你从来不用挑工具：说出你想要什么，它就用任务需要的那些——常常同时用好几样。这一页把这些手列出来，让你知道可以要什么。[把功能组合起来](./combine-features.md) 讲的是把它们连在一起时会发生什么。

最后一列说明每项在哪里能用。**桌面**是你电脑上的应用；**Web** 是 [chat.aeven.io](https://chat.aeven.io)。

## 在你的电脑上干活

| 能力 | 这样开口 | 在哪里 |
| --- | --- | --- |
| 文件夹里的文件 | “按每页上的日期给这些扫描件改名” | 桌面。在 Web 上，文件放在你的账号文件夹里 |
| 命令 | “把这个文件夹里的视频全部转成 MP4” | 桌面；Web 上在沙箱里运行 |
| 对话旁边的浏览器 | “打开供应商的网站，找到交货条款” | 桌面 |
| 你自己的浏览器 | “在我的 Chrome 里，从门户网站下载上个月的发票” | 桌面和 Web，通过 [Aeven 扩展](../using/browser.md#在你自己的浏览器里)——它在你其他的标签页里工作，用的是你的登录身份 |
| 你电脑上的应用 | “从我的记账软件导出本季度报表，存成 PDF” | 桌面 |
| 手机与模拟器 | “在 iPhone 模拟器里打开应用，截一张注册页面的图” | 桌面 |

**你电脑上的应用**就是电脑操控：Aeven 读取应用的窗口，像你一样在里面点击、输入和滚动。没有连接器、也没有网站的事情都走这条路——原生对话框、只有桌面版的程序。第一次使用时，macOS 会请你为它允许“辅助功能”和“屏幕录制”。

## 做出东西来

| 能力 | 这样开口 | 在哪里 |
| --- | --- | --- |
| 文档 | “把这些笔记整理成一份 Word 提案”、“把这些收据做成表格，按月汇总”、“根据这份报告做一份十页的演示文稿” | 桌面和 Web |
| 图表与分析 | “用这个 CSV 画出我们每月的销售额，告诉我哪里值得注意” | 桌面和 Web |
| 图片 | “一张复古风的里斯本旅行海报，顶部留出标题的位置” | 桌面和 Web |
| 视频片段 | “一段五秒的日落海浪，镜头缓慢向右平移” | 桌面和 Web |
| Motion 影片 | “用这三个数字做一段 30 秒的动画讲解，加上我们的标志” | 桌面和 Web |
| 网页与应用 | “给这次活动做一个单页网站，做好给我看” | 桌面；Web 上在你的账号文件夹里 |
| [分享回答](/docs/using/share-a-response) | 在任一回答下选择 **分享**，生成带预览卡片的公开链接；你的提问不会公开 | 桌面和 Web |

**视频片段和 Motion 影片不一样。**片段是生成出来的画面：用文字描述的一个场景。**Motion 影片**则是根据你给的内容逐帧画出来的——你的文字、你的数字、你的标志、你的照片——所以每个字都不会写错，每个数字都准确。它在对话里边做边播放；你可以要求修改（“慢一点”“第二个场景改成蓝色”），然后从影片自己的菜单导出 MP4。要营造气氛用片段，要准确表达内容就用 Motion：产品发布、业绩总结、社交帖子、简短教程。

图片和片段的细节见[图片与视频](../using/images-and-video.md)。

## 你给它的东西它都能读

附上文件，Aeven 就把它当作请求的一部分来读：PDF、Word、Excel、PowerPoint、纯文本和代码、图片和截图、扫描页（用文字识别读取），以及短视频片段。一次给好几份也没问题——“比较这三份报价，告诉我哪一份没算运费”。[对话与附件](../using/chat-and-attachments.md)

任务需要最新信息时，它也会自己上网搜索、阅读网页。

## 用说的，不用打字

- **听写**把你说的话变成消息框里的文字。在桌面应用里，语音在你自己的电脑上识别。
- **朗读这条消息**会把回复读给你听。让 Aeven 每个回答都朗读——练习外语时很有用——它就会一直读下去。

## 你的账号

连接邮箱、日历、网盘、GitHub、Slack、Teams、Discord、Telegram 和 WhatsApp，它们就成了任务的一部分：“找到 Anna 三月发来的合同”、“我周四的日程是什么”、“把这个发到 #launch”。任何会发送或改动东西的操作都会先问你。[连接器](../connections/connected-apps.md)

## 它会记住，也会学习

| 能力 | 带给你什么 |
| --- | --- |
| [记忆](../using/memory.md) | 人、项目、偏好和日期在对话之间延续——能追溯到几年前，不只是这一周 |
| [技能](../using/skills.md) | 每次都按同样方式执行的流程；输入 `/` 就能按名字启动 |
| [技能目录](./skill-catalog.md) | 现成的技能，涵盖写作、文档、研究、安全、设计、动效和代码 |
| [个性化](../account/personalisation.md) | 它跟你说话的方式，以及每次回答都会记着的备注 |

## 你不在时它也继续工作

| 能力 | 带给你什么 |
| --- | --- |
| [机器人](../automation/automations.md) | 按日程运行的任务，或在其他服务调用时运行。不需要你电脑上任何东西的机器人在 Aeven 云端运行，所以你关机时它们也照常工作 |
| [持续运行的工作](../using/background-jobs.md) | 长时间的命令、辅助 agent 和多步骤工作流，在你继续聊天的同时运行 |
| 并行的帮手 | “调研这五个竞争对手”可以由五个帮手同时进行，各自回报 |

## 在每台设备上

在另一台电脑或 [chat.aeven.io](https://chat.aeven.io) 上登录，同样的对话、记忆和设置都在。对话会留在最近处理它的那台设备上，连同它的文件和正在运行的任务；用 **选项 → 选择桌面设备** 可以移动它。[你的数据](../account/your-data.md#在你的其他设备上)

## 桌面版还是网页版？ {#desktop-or-web}

Aeven Web 是最快的入口：不用安装，你的对话和记忆都已经在那里。它在我们的服务器上、在一个有自己文件的沙箱里工作，并通过扩展访问你浏览器的标签页。单靠它自己碰不到你的电脑：没有你的文件夹、没有终端、没有应用、没有手机或模拟器，也没有对话旁边的浏览器。不过只要桌面应用开着，网页上的对话就会在你的电脑上运行，这些全都能用。[在 Aeven Web 上使用你的桌面设备](../using/desktop-from-web.md)

认真干活，请用桌面应用。[安装 Aeven](../getting-started/install-and-sign-in.md)
