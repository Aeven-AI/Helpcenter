# 值得设置的机器人

机器人就是一个会自己再次运行的请求。好的机器人替你做每周本来就要做的事，把结果送到你会看到的地方，没什么可说时就保持安静。下面每个例子都是你在 **Bots** 页面的输入框里输入的内容；Æven 会问它还缺什么，展示任务、什么会唤醒它、它的连接器和权限，在你确认之前什么都不保存。[机器人](../automation/automations.md)

**运行位置**说明每个机器人在哪里运行。只需要网络和已连接账号的机器人在 **Æven 云端**运行，你关机时也照常工作。需要你的文件、浏览器或应用的机器人在**你的电脑**上运行，前提是那里的 Æven 是打开的。

## 开启一天

**早间简报**——Æven 云端

> 每个工作日 7:30，告诉我今天的会议、需要我回复的邮件，以及本周到期的事情。控制在十行以内，通过 Telegram 发给我。

**会议准备**——Æven 云端

> 每个有外部来宾的会议开始前三十分钟，查一下谁会来、我们上次通过邮件和他们聊了什么，以及他们公司有什么新动态。用五条要点通过 Slack 发给我。

这个机器人由你的日历唤醒，而不是由时钟唤醒，所以会议改时间它也跟着改。

**生日和纪念日**——Æven 云端

> 每周一 8 点，根据你对我生活和工作中的人的了解，列出接下来两周的生日、纪念日和截止日期。没有的话就不用发。

## 管好收件箱

**整理**——Æven 云端

> 每当我的工作邮箱收到新邮件，给通讯和收据打标签，给客户来信加星标，能用两句话回复的就起草回复。永远不要发送。

它只在有邮件到达时才被唤醒，所以清闲的一天什么也不花。

**发票汇总到一张表**——Æven 云端

> 每月 1 日，在 Gmail 里找出上个月的发票和收据，把附件存到 Google 云端硬盘的“财务”文件夹，并把日期、供应商和金额加到“支出”表格里。

## 安排一周

**周五报告**——Æven 云端

> 每周五 16:00，汇总本周我们在 GitHub 上合并和关闭的内容，加上 Slack #product 里做出的决定，写一页周报，做成 Google 文档。把链接发到 #team。

**团队摘要**——Æven 云端

> 每天晚上 18:00，总结 Slack 上 #support 和 #sales 里最热闹的讨论：问了什么、还有什么没解决、谁在等谁。以私信发给我。

**周一计划**——Æven 云端

> 每周一 7:00，看看本周的日程和我的待办事项，标出排得太满的日子，并建议哪些会议可以挪。通过 Slack 发给我。

## 盯住变化

**价格或页面监控**——Æven 云端

> 每天早上 9 点，查看我们常去的三家店里 Sony WH-1000XM6 的商品页。只有价格低于 300 欧元时才在 Telegram 上告诉我。

**竞争对手动态**——Æven 云端

> 每周三，搜索我们四个竞争对手自上周以来的新闻、发布和价格变动。每个对手三条要点，附上来源链接，发邮件给我。

**需要登录的门户**——你的电脑

> 每周一，在我自己的 Chrome 里打开供应商门户，把新的发票下载到“发票”文件夹。

这个需要你的浏览器，所以它在你的电脑上、在那里的 Æven 打开时运行。

## 照看你的文件

**整理下载文件夹**——你的电脑

> 每周日晚上，整理我的“下载”文件夹：把文档、图片和安装包按类型和月份移进子文件夹，列出超过 1 GB 的文件但不要删除。

**备份检查**——你的电脑

> 每天晚上 23:00，检查“项目”文件夹今天是否已复制到备份盘，只有没复制时才告诉我。

## 由发生的事情唤醒

**版本发布公告**——Æven 云端

> 当我们应用的 GitHub 仓库发布一个 release 时，根据它的说明写一段简短的公告，发到我们 Discord 的 #announcements 频道和我们的 Telegram 频道。

之后机器人的页面会显示 payload URL 和密钥，把它们作为 Webhook 添加到仓库的设置里。“当发布一个 release 时”这句话很重要：没有它，机器人在发布前每一次草稿和编辑都会被唤醒。

**新的潜在客户**——Æven 云端

> 网站表单发来新的潜在客户时，调研这家公司，查一下我们以前是否给他们发过邮件，然后在 #sales 发一份简短介绍，附上建议的第一条消息。

带有**外部触发**的机器人有一个私密地址和一把密钥；任何东西向它发送请求都会启动一次运行。适用于表单、监控告警，或任何应该把工作交给 Æven 的服务。

## 机器人团队

**研究、写作、审稿**——Æven 云端

> 建一个看板：一个研究员机器人每周四收集本周我们市场的新闻，一个写手机器人把它们写成 Notion 里的通讯草稿，一个审稿人机器人对照我们的风格指南检查草稿，需要修改就退回给写手。看板每天控制在 200,000 个 token 以内。

每个机器人保留自己的连接器和权限，只把工作交给你给它连接的机器人，看板卡片会显示最近一条链。[看板](../automation/automations.md#boards)

## 让任何机器人更有用的方法

- **说清“完成”是什么样子。**“十行以内”“一页”“每个对手三条要点”——没有格式的机器人会写成长篇大论。
- **说清结果送到哪里。**Telegram 或 Slack 上发给你的消息、一个 Google 文档、文件夹里的一个文件、一个频道。只留在运行对话里的结果很容易被忽略。
- **说清没有新内容时怎么办。**“没有的话就不用发”能让机器人不变成噪音；这次运行会记为 **没有新内容**，连续几次会折叠成一行。
- **说清什么时候停。**“包裹送到后就停”能让机器人在任务完成时自己暂停。
- **让事件唤醒它，而不是时钟。**“收到新邮件时”“每个会议开始前三十分钟”“发布 release 时”只在真有事要做时运行，而不是每小时去查一次。
- **只给它需要的连接器和权限。**机器人在自己的连接器上不经询问就会行动，半夜也不会来问你，所以要看清这些，而不只是任务。“永远不要发送”“只起草”“不要删除”值得写进请求里。
- **先用“立即执行”试一次**，再放心交给日程；之后有任何改动，就在机器人页面的 **修改这个Bot…** 里输入。
- **看一下运行位置。**需要你的文件或浏览器的机器人只在你电脑上的 Æven 打开时运行；请保持 **后台运行** 开启。要换个地方运行，打开机器人，选择 **选择运行位置**。
- **从点子开始。****Bots** 页面里有按“按角色”“开启一天”“规划一周”“掌握动态”“工作与财务”“日常生活”分组的点子，**为你推荐** 会根据 Æven 对你的了解推荐机器人。
