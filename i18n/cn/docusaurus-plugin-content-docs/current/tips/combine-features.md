# 把功能组合起来

每项功能单独用，能省几分钟；串在一起，能省下一个下午。你不需要把工作拆成步骤：在一条消息里描述整件事，Aeven 会依次去读、去做、去检查、去交付。凡是要以你的名义发出去的东西，它都会先停下来问你。

下面每个例子都是可以直接粘贴再改的请求。箭头表示它把哪些功能串在一起。

## 从客户邮件做一部影片，分享给团队

> 读一下 Northwind 最近那封关于春季活动的邮件。做一部 30 秒的 Motion 影片，展示其中三个要点，用附件里他们的标志。然后把 MP4 发到 Slack 的 #marketing，以及我们的 Telegram 团队群，附两行摘要。

**邮件 → 附件 → Motion → Slack 和 Telegram。**Aeven 找到邮件，从中取出标志，写好影片并在对话里播放，渲染出 MP4，再起草两条帖子。每条帖子发出前你都会看到。先看影片，要改就说——“短一点”“数字再大些”“加荷兰语字幕”——再让它发。

## 准备明天的会议

> 看看我明天的日程。每个和公司外部的人开的会，都把我和对方最近的邮件往来、以及你记得的关于对方的事收集起来，每个会写一页简报，放在一个 Google 文档里。

**日历 → 邮件 → 记忆 → 文档。**让这件事做得好的是记忆：它带来以前对话里的背景——谁决定了什么、对方在意什么、谁的生日快到了。

## 手机上的缺陷，附证据提交

> 在 iPhone 模拟器里打开我们的应用，用一个测试邮箱注册，然后进入设置。如果头像上传失败，就把每一步截图，在我们应用的 GitHub 仓库里开一个 issue，写上步骤并附上截图。

**手机与模拟器 → 截图 → GitHub。**用 Android 模拟器也一样。

## 从调研到演示文稿

> 调研我们产品最大的五个竞争对手：定价、定位、最近的发布。把结果放进一个注明来源的表格，画出价格对比图，再据此做一份十页的演示文稿。起草一封带上这份演示文稿的邮件给 Sam。

**网络搜索 → 并行的帮手 → 表格和图表 → 幻灯片 → 邮件草稿。**调研量大时，Aeven 会把它分给几个同时工作的帮手；[任务列表](../using/background-jobs.md)里能看到它们。

## 进入只有你能打开的网站

> 在我自己的 Chrome 里，进入供应商门户，下载十月份的所有发票，存到“发票”文件夹，再做一个包含日期、编号和金额的表格。

**你的浏览器 → 文件 → 表格。**扩展在你的浏览器里、用你的登录身份工作，所以 Aeven 能进入没有连接器的网站。提交表单或确认任何东西之前它都会先问你。

## 没有连接器的程序

> 打开我的记账软件，把第三季度的损益表导出为 PDF，然后总结与第二季度相比最大的三项变化，并在 WhatsApp 上起草一条给会计师的消息。

**电脑操控 → 读取 PDF → 分析 → WhatsApp。**电脑操控通过窗口操作你电脑上的任何应用——适合没有连接器也没有网站的桌面程序。

## 跟上一个热闹的群

> 总结一下这周家庭 WhatsApp 群里发生的事，列出有人直接问我的问题，并起草我可以发的简短回复。

**WhatsApp 或 Telegram → 摘要 → 草稿。**每条回复你批准之前都不会发出。

## 先写好，再让它听起来像你

> 起草一封回复，回应 Anna 关于延迟发货的投诉：道歉，说明是承运商延误，下一单免运费。然后用 humanizer 处理一遍，让它读起来像我写的，存为 Gmail 草稿。

**邮件 → 写作 → humanizer 技能 → 草稿。**[humanizer](./skill-catalog.md) 会去掉让文字听起来像机器写的痕迹，但不改变它要说的内容。

## 弄清某个东西是怎么工作的

> 这个文件夹里有一个我装的 Electron 应用。弄清它向服务器发送了什么、把我的数据存在哪里。写成一份简短的报告。

**文件 → 逆向工程技能 → 报告。**在没有源代码可读时，逆向工程技能直接读已发布的软件本身——应用包、二进制文件、数据库、网络抓包。

## 让它自己运行

上面任何一个请求都可以变成机器人：某次运行效果好时，说一句*“把它做成每周一早上 8 点运行的机器人”*。Aeven 会把这段对话变成一个定时任务，给你看它要做什么、可以用哪些账号，然后等你同意。[值得设置的机器人](./useful-bots.md)

## 让串联顺利的诀窍

- **说清结果放到哪里。**“存到报告文件夹”“发到 #team”“做成 Google 文档”——否则结果只留在对话里。
- **有多个账号时说出名字。**“用我的工作 Gmail”“在 Acme 的 Slack 里”。
- **要求一个检查步骤。**“发之前先给我看影片”或“做表之前先列出发票”，就能把暂停放在你想要的地方。
- **边做边改。**串联仍然是一段对话：改其中一环——“用第二个标志”“不发 Telegram”——Aeven 只重做受影响的部分。
- **留住好用的做法。**“记住 Northwind 要荷兰语字幕”会为下次保存下来，Aeven 也会自己学会效果好的流程。
