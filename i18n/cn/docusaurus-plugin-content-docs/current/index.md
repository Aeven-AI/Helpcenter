# 帮助中心

Aeven 是一个在你的电脑上、在你连着的各个应用里做事的 AI。你说出你想要什么；Aeven 想出步骤，把它们做掉，并且在任何需要你点头的事情之前先问你。

这些页面是写给“用 Aeven”的，不是写给“拿它来做开发”的。每一页都从你眼前那块屏幕开始，以某件事做完结束。

## 从哪里开始

- **第一次来？** 先 [安装 Aeven 并登录](./getting-started/install-and-sign-in.md)，然后 [做完第一个任务](./getting-started/your-first-task.md)。
- **想知道这一个为什么不一样？** [Aeven 在你的电脑上运行，把它学到的东西存在你拥有的地方，从不读你的记忆，而且是开源的](./getting-started/why-aeven.md)。
- **每天都用？** 了解 [审批是怎么运作的](./using/approvals.md) 和 [你的成果落在哪里](./using/where-your-work-lands.md)。
- **想让它自己跑？** 配一个 [bot](./automation/automations.md)。
- **要把邮件、日历或聊天接进来？** 在 [连接器](./connections/connected-apps.md) 里接上。
- **想把一件事教它一次？** [技能](./using/skills.md) 存着流程；[bot](./automation/automations.md) 按时按点跑它。
- **哪个模型来回答？** [Aeven 模型](./using/models.md) 已经包含在内、随时可用；你自己的 key 也一样能行。
- **有什么地方不工作？** [修好一个问题](./help/troubleshooting.md)。
