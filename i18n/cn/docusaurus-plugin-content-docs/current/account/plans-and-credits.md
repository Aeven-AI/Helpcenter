# 账号、套餐与积分

账号页面是回答“我在哪个套餐上、用了多少、还剩多少”的那一个地方。里面没有一项需要发支持请求。

## 你的账号

**Account**——在角落里点头像进去——放着你的姓名和照片、你的语言、你的套餐、你的积分余额、本周期的用量、账单、two-factor authentication，以及 **Sign out**。

在第二台电脑上用同一个账号登录，记忆、对话和设置都跟着过去。[你的数据](./your-data.md) 说了这些副本住在哪儿。

## 套餐

| 套餐 | 它是给什么用的 |
| --- | --- |
| Free | 一份预览额度，够你在付钱之前好好用一用 Aeven |
| Pro | 每月一份额度，加上 Aeven Flash 和 Pro 模型——大多数人想要的套餐 |
| Heavy | 几倍于 Pro 的额度，给整天都在跑的工作 |

账号页面显示你这个账号的确切数字、当前套餐包含什么，以及它是续订还是到期——连同日期。**Upgrade** 和 **Downgrade** 就在你所在套餐的旁边。

还没开放订阅的套餐会自己说明；在它开放之前，靠积分走。

## 换套餐

| 动作 | 会发生什么 |
| --- | --- |
| Upgrade | 立即生效。今天付按比例折算的差额，更大的额度马上就能用 |
| Downgrade | 安排在续订时生效。在那之前，你保留现在的套餐和额度 |
| Cancel | 套餐留到本期结束，之后回到 Free |

结账在你浏览器里打开；付款完成时账号页面自己就更新了，没有什么要刷新或确认的。

如果付款失败，会有一条横幅说明，并请你更新付款方式——你处理的时候，套餐保持原样。

## 积分

用量按积分计量：一次请求花掉多少，看回答它的是哪个模型、它做了多少工作。

- **先花套餐额度。** 本期的额度用完之后，才开始花积分。
- **积分不会过期。** 你加进去的积分留在账号上，直到被花掉。
- **随时都可以加积分**，就在账号页面上：选一个金额或者自己填，通过 Stripe 付款，钱一到账余额就更新。
- 充值不是每个部署都开放；不开放的地方，页面会这么说，而不是给你一个结账入口。

一期的额度快用完时，Aeven 会说一次，并指着两条路：更大的套餐，或者更多积分。

## 用量

用量一节讲的是当前这一期——起止日期、额度花掉了多少、花在哪儿。这才是“这个月为什么贵了”的诚实答案：大模型上的长任务，和小模型上的短问题不是一回事。[选一个模型](../using/models.md)

## 账单与发票

**Manage billing** 打开账单门户：付款方式、过往发票、收据和 VAT 信息都在那儿，换卡也在那儿办，不在 Aeven 里办。

## 用完的时候

需要超过剩余额度的任务会停下来，并告诉你。加积分，或者换到一个包含更多额度的套餐，然后在同一段对话里接着做——已经做完的不会重做。

## 安全

Two-factor authentication 用的是身份验证器应用：扫那个码，确认一组六位数字，然后把它给你的恢复码收好——每个只能用一次，丢了应用的时候，它们就是你回来的路。关掉它同样要一组码，所以一个被偷走的会话没法悄悄把它移除。
