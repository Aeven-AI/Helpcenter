# Aeven 如何与你对话

两个人问同一个问题，想要的答案并不相同。**Settings → Personalization** 就是你说出自己喜欢哪一种的地方：语气、长度、语言，以及它应该停止做的事。

改动从你的下一条消息起生效；已经出现在一段对话里的内容不会被改写。

## 语气

| 语气 | 听起来像 |
| --- | --- |
| 自动 | 读懂当下：工作要简短准确，生活要温暖贴心，训练时要给人打气。默认设置 |
| 温暖 | 每一条回答都真正温暖友好，工作场合也一样 |
| 直接了当 | 每一条回答都简短平实，个人话题也一样 |
| 俏皮 | 轻松随意，留出幽默的空间 |

自动是最不容易让人意外的设置：它随着对话改变语域。如果你宁愿处处只有一种语气，选定它，Aeven 就不再自行调整。

## 关于你答案的备注

备注栏留给其余的一切：*“工作之外随意一点。我用荷兰语写，你就用荷兰语答。私人话题不要用项目符号列表。”* 你要什么、不要什么都写出来；两者都会被读到。

字数有上限，输入时栏内会显示计数。保存就够了——不用重启，也不用新开一段对话。

## 主提示词

备注下面是主提示词：定义 Aeven 是谁的那些指令。你自己的主提示词只在你自己的会话里取代内置提示词，这样你得到的是一个性格不同的助手，而不是一个调过参数的助手。重置会回到内置提示词。

被委派的帮手代理沿用内置提示词，所以无论你在这里写什么，Aeven 交给它的工作都会表现一致。

## 这里没有的东西

- **关于你的事实**属于[记忆](../using/memory.md)，不属于个性化。这一页讲 Aeven 怎么说话；记忆讲它知道什么。
- **由哪个模型回答**在消息框里选。[选一个模型](../using/models.md)
- **多常先问你**是一项权限设置。[Aeven 会先问什么](../using/approvals.md)
