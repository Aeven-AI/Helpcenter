# 你的数据

Aeven 用你自己的文件，在你自己的文件夹里，在你自己的电脑上工作。这一页说清楚什么住在哪儿。

## 在你的电脑上

- **你的文件**留在原地。Aeven 在你选的文件夹里读写它们，不会把你的文件夹拷到别处。
- **对话和设置**存在你电脑上 Aeven 自己的数据文件夹里，所以你再打开应用时，之前的对话还在。它同时也会同步一份到你的账号，好让它们出现在你别的设备上。
- **登录状态**留在那台电脑上，所以你不必每次打开都重新登录。

## 在你的其他设备上

在第二台电脑上登录同一个账号，它显示的是一样的记忆、对话、设置和个性化。每一处改动都在发生改动的那台设备上加密，再送到你的账号；别的设备把它取过去，两台都在线时通常在一秒之内。

**Settings → Sync** 列出你账号上的设备，显示这一台是不是最新的，还有一个 **Sync this device**，它让某台电脑停止同步，而不删掉它已经存下的东西。**Remove** 把一台设备从那份名单上清掉；一台还在登录、还在同步的电脑，下次同步时会把自己又加回来。

同步的那份副本以加密形式存在 Aeven 的服务器上，Aeven 拿着打开它的密钥。Aeven 不读你的记忆：能碰它的只有运行这个服务的人，而且都有记录。端到端保护——密钥留在你自己的设备上，只有你能打开同步的东西——正在逐步铺开。

## 在 Aeven 的服务器上

你的账号、套餐和积分余额跟着你的 Aeven 账号走。在你的设备之间移动的那一份记忆、对话、设置和个性化也存在那里，好让一台离线过的设备能追上。连着的服务是靠你登录时提供方签发的令牌访问的；在你移除连接之前，让连接一直有用的就是这些令牌。

一项任务的内容会送给回答它的模型，好把回答做出来。[选一个模型](../using/models.md) 说了是哪个模型在回答。

## 拿掉一些东西

| 要拿掉 | 这样做 |
| --- | --- |
| 一段对话 | 从侧边栏删掉它 |
| 一条记忆 | 在 **Settings → Memory** 里移除它 |
| 一个连接 | 在 **Settings → Connectors** 里移除，或者在提供方那边撤销 |
| 你导入的技能 | 在 **Settings → Skills** 里 **Remove skill** |
| 你的账号和它的数据 | 用账号页面里的删除选项，或者从 [aeven.io](https://aeven.io) 联系我们 |

删掉一个 bot 会停掉它以后的运行；它已经产出的文件留在你的文件夹里，直到你删掉它们。
