# 隐私政策

**最后更新：2026 年 11 月 7 日**

Aeven 是一个桌面应用，它造出来就是为了让你用它做的大部分事留在你自己的电脑上。这一页说什么会离开它、为什么离开，以及你能对此做什么。Aeven Web，也就是 [chat.aeven.io](https://chat.aeven.io)，把同一个助手放在我们的服务器上运行，而不是你的电脑上；[在 Aeven Web 上](#在-aeven-web-上) 说明这带来哪些不同。

它管的是 Aeven 应用、这个帮助中心，以及它们背后的 Aeven 账号。它不管的是你接到 Aeven 上的那些服务——邮件、日历、聊天、代码托管——它们各自有自己的政策。

## 1. 谁负责

Aeven 由位于荷兰的 **[legal entity name]**（[registered address]）提供（“Aeven”、“我们”）。这一页上的任何事，写信到 [privacy@aeven.io](mailto:privacy@aeven.io)。

## 2. 什么留在你的电脑上

这些东西存在本地，在 Aeven 运行那台机器上它自己的数据文件夹里：

- **你的文件。** Aeven 在你选的文件夹里读写文件。它们留在原地。
- **你和 Aeven 的对话**，除非某个模型需要收到一段才能回答（见第 5 节）。
- **你的设置**，包括你选的文件夹、你的审批策略，以及你写下的常驻指令。
- **你的记忆**，也就是 Aeven 在对话之间留住的事实、偏好和学到的做法，除非你选择把这一层托管在别处。
- **你的登录状态**，对应你登录时用的那个账号。

对话、设置和记忆也会同步到你的 Aeven 账号，好让它们跟着你到你别的设备上；第 10 节说那份副本是怎么保护的。你可以按设备关掉同步，在 **Settings → Sync** 里。

你可以删掉其中任何一样：在应用里删掉对应的条目，或者删掉 Aeven 的数据文件夹。[你的数据](../account/your-data.md) 列出了每一样住在哪儿。

### 在 Aeven Web 上

使用 Aeven Web 时，你的电脑上什么也不运行，所以桌面版存在本地的东西改存在我们的服务器上：

- **你的对话、记忆、设置和个性化**，跟你的账号存在一起，助手才能接着做下去。
- **你上传**到对话里的文件。
- **你的账号文件夹**：助手为你创建或修改的文件，比如图表、表格、文档和视频，每个账号最多 5 GB。它们在对话之间一直留着，直到你或助手把它们删掉。

为了回答你，我们的服务器会读取这些内容，并把任务需要的部分交给模型，如第 5 节所述。所以它**不是端到端加密的**：跟第 10 节里同步的那份副本不同，Aeven 的系统能打开它。Aeven 没有人读你的内容，能碰存放它的系统的，只有运行这个服务的人，而且都有记录。如果你需要对话和文件从不存放在我们的服务器上，请用桌面应用。

助手为你运行的命令，比如分析数据或画图，在一个隔离的沙箱里运行，它只看得到你自己的账号文件夹，也上不了网。你的账号文件夹没有备份；丢不起的东西，请自己留一份。

## 3. 什么在我们这边

| 什么 | 为什么 | 例子 |
| --- | --- | --- |
| 账号身份 | 为了让你登录，并把你的套餐挂在你身上 | 你登录时 Google、Apple 或 X 返回的姓名、邮箱地址和提供商账号 ID |
| 套餐与积分 | 为了计量用量、把账算对 | 当前套餐、积分余额、充值、调整 |
| 付款记录 | 因为发票和税务记录是法律的要求 | 金额、日期、发票、卡号后四位；卡号由我们的支付服务商处理，不是我们 |
| 技术日志 | 为了保持服务可用、安全 | 应用版本、平台、错误报告、请求时间、从 IP 得出的粗略位置 |
| 支持对话 | 为了回答你 | 你发给支持的消息 |
| 同步的数据 | 为了让你登录的每台设备上都有你的记忆、对话、设置和个性化 | 这些条目的加密更新，以及你设备的名单 |
| Aeven Web 的数据 | 为了让助手不用你的电脑也能替你干活 | 对话、记忆、设置、上传的文件，以及你账号文件夹里的文件 |
| 注册所用的网络 | 为了让免费预览积分只给每个网络有限几个账号，不能被反复领取 | 你注册时所用网络（你的 IP 地址，或 IPv6 地址所在的地址段）的带密钥哈希，从不存地址本身 |

我们不从任何人手里买关于你的个人数据，也不卖或者租我们存下的东西。

## 4. 我们凭什么可以处理它

在 GDPR 之下，我们依据：

- **履行合同**——让服务跑得起来的账号、套餐、积分和账单。
- **正当利益**——保持服务安全、诊断故障、防止滥用，以及改进它的行为方式。我们会拿这些利益和你的权利相权衡。
- **法律义务**——发票、税务，以及回应合法的请求。
- **同意**——当我们要求的超出上面这些时，比如可选的产品邮件。你随时可以撤回。

## 5. 模型回答的时候

为了做出一个回答，一项任务的内容——你的消息、Aeven 为它读过的你那部分文件、你附上的图片，以及相关的对话历史——会被送到正在回答的那个模型。

- **Aeven 模型。** 任务去我们和我们的处理者一起运营的模型基础设施，受一份数据处理协议约束，那份协议禁止拿它给任何别的人训练模型。
- **你自己的提供商。** 如果你接了，任务直接去那个提供商那里，受它的条款和它的隐私政策管。那是你选的；我们不夹在中间。

我们不拿你的内容训练模型。如果有模型提供商参与，那也是他们对我们的承诺，并且写进了我们跟他们的协议里。

换一个模型回答，不会挪动你的记忆、对话或连接。[选一个模型](../using/models.md) 讲了这个选择。

## 6. 连着的账号

当你连上 Gmail、Google Drive、Outlook、Slack、Discord、Telegram、WhatsApp、GitHub 或者别的服务时，提供商会签发一个令牌，Aeven 用它代你行事。那个令牌由 Aeven 存着，连接在多久就存多久。

- 我们不向你要那些服务的密码。
- 在 **Settings → Connectors** 里移除一个连接，会把令牌在我们这边删掉；在提供商自己的设置里撤销 Aeven，从他们那边起到同样的作用。
- Aeven 在一个连着的服务里能读什么、写什么，受你连接时给的那份范围限制。

## 7. 还有谁看得到你的数据

我们只跟这些共享个人数据：

- **托管和基础设施提供商**，跑我们的账号服务的，在欧盟之内，或者在欧盟批准的保障措施之下。
- **我们的支付服务商**，为了订阅、积分和发票。
- **模型提供商**，为了发给它们的任务，如第 5 节所述。
- **邮件和支持工具**，在你写信给我们的时候。
- **主管机关**，在法律要求、而且请求有效的时候。

处理者的当前名单可以向 [privacy@aeven.io](mailto:privacy@aeven.io) 索取。数据离开欧洲经济区的时候，是依据欧盟委员会的标准合同条款或者一项充分性决定走的。

## 8. 我们留多久

| 东西 | 留多久 |
| --- | --- |
| 账号和套餐 | 你的账号在多久就留多久 |
| 付款和发票记录 | 七年，荷兰税法要求的 |
| 技术日志 | 30 天，除非要用来调查一起安全事件 |
| 支持对话 | 最后一条消息之后两年 |
| 同步的数据 | 你的账号在多久就留多久——在应用里删掉它，同步的副本里也就没有了 |
| Aeven Web 的数据 | 你的账号在多久就留多久，或者直到你删掉某个对话或文件 |
| 注册所用的网络 | 注册后 30 天 |
| 你电脑上的其他任何东西 | 直到你删掉它——我们没有副本 |

删掉你的账号会删掉我们持有的账号数据，包括那份同步的副本，以及 Aeven Web 为你存下的一切。你电脑上别的文件和对话还留在那儿，因为它们从来不是我们的。

## 9. 你的权利

你有权看到我们持有哪些关于你的东西、要求更正、要求删除、以可携带的格式拿到它、反对基于正当利益的处理，以及撤回你给过的同意。写信到 [privacy@aeven.io](mailto:privacy@aeven.io)；我们 30 天内回答。

如果你对我们的回答不满意，可以向荷兰的数据保护机构，也就是 **Autoriteit Persoonsgegevens**，或者你住的地方的监管机构投诉。

## 10. 安全

应用和我们服务之间的流量在传输中加密。存在那里的账号数据由我们的托管提供商加密。对生产数据的访问只给运行这个服务需要它的人，而且都有记录。

在你的设备之间同步的那一份记忆、对话、设置和个性化，在离开应用之前就加密了，存着它的那个中继也让它保持加密。Aeven 拿着打开那份副本的密钥；我们不用它来读你的记忆。Aeven 没有人读你的记忆、翻你的记忆，能碰存放它的系统的，只有运行这个服务需要它的人，而且都有记录。密钥留在你自己的设备上、那份副本我们完全打不开的保护，正在逐步铺开。

在 Aeven Web 上，你的内容存在加密的磁盘上，并由你账号的登录保护，但不是端到端加密的，原因见 [在 Aeven Web 上](#在-aeven-web-上)。运行命令的沙箱按账号隔离，并以一个单独的系统用户运行，读不到我们服务器上的其他东西。

没有哪个系统是完美的。如果你发现一个漏洞，报告给 [security@aeven.io](mailto:security@aeven.io)，别把它公开，我们会跟你一起处理。

因为 Aeven 在 Apache 2.0 许可下开源，你也可以读代码，看它拿你的文件做什么：[github.com/Aeven-AI/Aeven](https://github.com/Aeven-AI/Aeven)。

## 11. 儿童

Aeven 不是给 16 岁以下的人用的。我们不故意收集他们的数据；如果你认为某个孩子有账号，写信给我们，我们会把它删掉。

## 12. Cookie 和这个帮助中心

这个站点是一个静态文档站点。它不设广告 Cookie，也不跑任何能认出你的分析。它在你的浏览器里只存你喜欢浅色还是深色，以及内存里的搜索索引。[aeven.io](https://aeven.io) 有它自己单独的一份声明。
