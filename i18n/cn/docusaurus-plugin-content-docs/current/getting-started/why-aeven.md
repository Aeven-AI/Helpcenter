# Aeven 的不同之处

大多数 AI 工具是别人服务器上的一个聊天框。你的工作传上去，一个答案传下来，而工具学到的关于你的东西留在他们那边，用他们的格式，绑在他们的模型上。

Aeven 是反过来建的。Æven 里的 Æ 也代表 **Almost Everywhere**（几乎无处不在）：无论你在哪里，你的工作、你的记忆和你的电脑都触手可及。由此有四件事，每一件你今天都能在应用里自己验证。

## 1. 它在你的工作已经所在的地方工作

一个任务很少只待在一个地方。一条消息提到一份文档，这份文档属于一个项目，而这个项目有文件、有一个仓库，还有散落在早前对话里的决定。

Aeven 在你自己的电脑上你选定的那个文件夹里工作，并伸进你连接的账号。它读取那里的文件，运行命令，打开浏览器，把它做出来的东西留在同一个文件夹里。你不必把工作上传到一个聊天窗口再下载一个结果；工作留在原处，Aeven 在其中穿行。

**这意味着：** 要求一件横跨你的邮件、你的文件和你的仓库的事，它能做完整件事，而不是只做能塞进一个文本框里的那部分。

## 2. 它学到的东西归你

Aeven 在模型之上保留一层：它对你的了解、对你工作的了解、你连接过的账号、你安装的技能、它第一次做成功某件事时摸出来的流程。这一层不是某个厂商云端里的功能。它是你的，可以带走，而且不是我们会去读的东西。

- **可读。** 打开 **Settings → Memory**，看看里面有什么。
- **可改。** 改掉一行错的，删掉一行你不想再被用到的。
- **可搬。** 它可以放在你的笔记本上，放在角落里的一台机器上，放在你自己的云里，或者放在我们这里。这四种情况下它都是同一层。
- **离开时也归你。** 导出它，带到别处去，在你不再使用 Aeven 之后仍然留着。
- **我们不会读。** Aeven 不读你的记忆。让你的多台设备保持同步的那份副本是加密的，而访问承载它的那些系统的权限只给运营这项服务的人，并且留有记录。
- **你所在之处皆可用。** 在第二台电脑上登录，同样的记忆、对话和设置已经在那里了。[你的数据](../account/your-data.md) 说明了每份副本存放在哪里。

**这意味着：** 使用 Aeven 的价值积累在一件你拥有的东西里，而不是一个你租来的账号里——而且是在一件我们从不打开的东西里。花一年时间教它认识你的客户、你的格式和你的快捷做法，得到的是一份资产，而不是一项订阅功能。

## 3. 模型是一个可以换掉的部件

Aeven 在设计上就不依赖某一个模型。Aeven 模型随应用一起提供，不需要任何设置；你自己的 API key、一个 OpenAI-compatible 端点、你在别处订阅的模型，或者一个跑在你自己的机器上的模型，都同样支持。

因为你的上下文活在模型之上，换一个模型不花你任何代价：对话、记忆、连接和技能都原样留在那里。

**这意味着：** 你不是把工作流程押在一个供应商的路线图、价格或政策上。当有一个更好或更便宜的模型出现时，你换过去，并保留你已经建立起来的一切。[选择模型](../using/models.md) 讲了怎么做。

## 4. 它是开源的

Aeven 以 [Apache 2.0 许可证](https://github.com/Aeven-AI/Aeven/blob/main/LICENSE) 开源，公开在 [github.com/Aeven-AI/Aeven](https://github.com/Aeven-AI/Aeven)。

- **你可以查它。** 它读什么、发什么、什么时候问——在代码里，而不是在一句承诺里。
- **你可以改它。** 每一项能力都是一个插件：agent 循环、模型适配器、工具、权限、存储、界面。换掉其中一部分，而不必 fork 整个东西。
- **它比我们活得久。** 如果我们明天消失，代码还在，而承载你上下文的那一层已经归你了。

**这意味着：** 上面这四项说法不是要你只能相信的宣传文案。它们是可以读到的软件属性。

## 你第一周还会注意到的另外两件事

**它在动手之前先问。** Aeven 能读文件、运行命令、打开网页，所以在任何有后果的动作之前，它会给你看确切的操作并等待。你可以允许一次、允许这个任务，或者完全不允许。[Aeven 会先问什么](../using/approvals.md)

**它学会你做事的方式。** 教它一次你的做事方式——一个报告格式、一份评审清单、一个部署步骤——它就会把它留成一项技能或一个流程。机器人把一句话变成一个按自己的时间表运行的任务。[Aeven 会记住什么](../using/memory.md) · [技能](../using/skills.md) · [机器人](../automation/automations.md)

## Aeven 不是什么

把另一面也讲清楚，是同一份坦诚的一部分：

- **它在浏览器标签页里发挥不出全部能力。** [chat.aeven.io](https://chat.aeven.io) 让你在任何地方都能开始，并通过扩展访问你浏览器的标签页，但单靠它自己时，它在我们服务器上的沙箱里工作：没有你的文件夹、没有终端、碰不到你电脑上的应用和手机；只有桌面应用开着时，网页上的对话才会[在你的电脑上运行](../using/desktop-from-web.md)。认真干活，请安装桌面应用，随之而来的是对你电脑的访问权限。[Aeven 能做的一切](../tips/everything-aeven-can-do.md#desktop-or-web)
- **它不是“什么都不共享”的承诺。** 一个任务会发给为它作答的模型，而你的账号、套餐和账单都在我们这里。[隐私政策](../legal/privacy.md) 确切说明了什么会离开你的机器。
- **它没有完工。** Aeven 处于开发者预览阶段：功能和数据格式仍可能变化。
- **它不是权威。** 模型有时会出错，所以在依赖要紧的事情之前先核实。
