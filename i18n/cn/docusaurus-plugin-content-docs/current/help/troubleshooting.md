# 修好一个问题

大多数问题都落在那几个情形里。从症状开始。

## 一条消息立刻就失败

| 你看到的 | 可以试的 |
| --- | --- |
| 登录或权限错误 | 从账号菜单退出，再登录回来 |
| 一条关于积分或套餐上限的消息 | 看看[账号、套餐与积分](../account/plans-and-credits.md) |
| 点名了提供商的模型错误 | 在 **Settings → Models** 里换一个模型，然后重发 |
| 一条关于网络的消息 | 检查你的网络连接；如果你在代理后面，先把代理设好再重试 |

## 一个任务做到一半停了

读那段对话的最后一行：它说出了是什么失败了。发一句“继续”会从停下的地方接着做。如果同一个步骤失败两次，通常说明那个请求太宽了——把它拆成两个小一点的。

## 一个连着的应用不工作了

它的访问权被撤销或者过期了。打开 **Settings → Connectors**，重新关联那个账号，然后重试这个任务。[连接器](../connections/connected-apps.md)。

## 一个文件没出现在你等它的地方

看看文件夹控件里的那个文件夹——任务会写进给它的那个文件夹。那段对话会列出它写下的每一个文件，所以在对话里搜那个名字。

## 新版本装不上

Aeven 在你退出时安装更新。完全退出——从应用菜单退出，而不是只关掉窗口——然后重新打开。如果它还是报同一个版本，应用菜单里的 **Check for Updates…** 会说更新器发现了什么。

## 这里没有对得上的

把发生了什么发给 [help@aeven.io](mailto:help@aeven.io)：你要的是什么、你看到了什么，以及它发生的时间。一张对话的截图通常就够我们复现了。
