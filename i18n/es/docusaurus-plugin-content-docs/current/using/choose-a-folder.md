# Elegir una carpeta

Æven trabaja en una carpeta que eliges tú, no en toda tu computadora. La carpeta es el límite: los archivos que puede leer y cambiar, y el lugar donde aparecen los resultados.

## Elige una

1. Selecciona el control de carpeta en la pantalla de conversación.
2. Elige la carpeta que contiene el trabajo: un proyecto, un conjunto de documentos, los archivos de un cliente.
3. Pide lo que quieres en el cuadro de la conversación.

Elige la carpeta antes de pedir, para que Æven lea los archivos correctos.

## Qué significa la carpeta

- Los archivos que están dentro se pueden leer mientras Æven trabaja.
- Los archivos que Æven crea o cambia quedan ahí.
- Todo lo que está fuera queda fuera de su alcance salvo que lo permitas de otro modo.

## Cambiar de carpeta

Elige otra vez el control de carpeta y selecciona otra carpeta. La conversación se mantiene; los archivos que Æven puede ver cambian.
