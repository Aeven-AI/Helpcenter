# Lo que Aeven pregunta antes de actuar

Aeven puede leer archivos, ejecutar comandos, abrir páginas y cambiar cosas en tus aplicaciones conectadas. Antes de cualquier acción con consecuencias, pregunta. La pregunta nombra la acción con palabras sencillas, para que puedas valorarla.

## Cómo responder

| Opción | Qué hace |
| --- | --- |
| Allow once | Esta acción se ejecuta ahora. Aeven volverá a preguntar la próxima vez. |
| Allow for this task | La acción puede repetirse mientras se ejecuta esta tarea. |
| Don't allow | La acción no se ejecuta, y Aeven lo sabe para poder buscar otra forma. |

Si una pregunta no queda clara, pregunta en la conversación antes de responder: «¿qué hace ese comando?» es una respuesta razonable.

## Con qué frecuencia pregunta

**Settings → General** contiene el ajuste de permisos. Los ajustes más estrictos preguntan más a menudo y son el valor predeterminado adecuado mientras te acostumbras a lo que hace Aeven. Un ajuste más permisivo deja que una tarea larga avance sin interrupciones.

## Cuando no estés seguro

Decir no no te hace perder nada. Aeven continúa con lo que tiene permitido y te dice qué no pudo terminar.
